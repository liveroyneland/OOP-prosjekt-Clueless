# OOP-prosjekt – Clueless

Dette prosjektet ble utviklet som prosjektoppgave i faget TDT4100 – Objektorientert programmering ved NTNU.

Prosjektet er inspirert av klesskapet til Cher fra filmen *Clueless*. Målet med prosjektet er å lage en applikasjon hvor brukeren kan organisere klær, sette sammen antrekk og utforske ulike kombinasjoner.

## Funksjonalitet

- Legge til, redigere og fjerne klær
- Organisere klær etter ulike kategorier
- Sette sammen antrekk
- Utforske og administrere klesskapet
- Lagre og lese informasjon om klær og antrekk

## Teknologier

- Java
- JavaFX
- Maven
- JUnit
- Objektorientert programmering

## Hva jeg lærte

Gjennom prosjektet fikk jeg praktisk erfaring med objektorientert programmering og utvikling av en større Java-applikasjon. Jeg jobbet blant annet med klasser og objekter, arv, grensesnitt, filhåndtering, testing og JavaFX.
